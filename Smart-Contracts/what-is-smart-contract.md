# What is a Smart Contract?

## Definition

A smart contract is a self-executing program stored on a blockchain that runs when predefined conditions are met.

It automates agreements without intermediaries.

---

## Why Smart Contracts Exist

They reduce:

- Trust requirements
- Manual processes
- Third-party costs

---

## How They Work

1. Code is deployed to the blockchain.
2. Users interact with the contract.
3. The network executes the logic.
4. Results are recorded immutably.

---

## Use Cases

- DeFi lending
- NFT minting
- DAO governance
- Token transfers

---

## Advantages

- Transparent
- Tamper-resistant
- Automated

---

## Key Takeaways

- Smart contracts are blockchain programs.
- They execute automatically.
- They enable decentralized applications.
