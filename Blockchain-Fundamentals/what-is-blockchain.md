# What is a Blockchain?

## Definition

A blockchain is a distributed digital ledger that records transactions across multiple computers in a way that is transparent, secure, and tamper-resistant.

Instead of one central authority maintaining records, the network collectively maintains the data.

---

## Why Blockchain Exists

Traditional systems rely on trusted intermediaries like banks or institutions.

Blockchain was created to:

- Remove the need for central trust
- Prevent data tampering
- Enable transparent verification
- Allow peer-to-peer value transfer

---

## How It Works

1. Transactions are requested.
2. Transactions are grouped into blocks.
3. Blocks are validated by network participants (miners or validators).
4. The validated block is added to the chain of previous blocks.

Each block contains:

- Transaction data
- Timestamp
- Cryptographic hash of the previous block

This linking makes the chain tamper-resistant.

---

## Real World Example

Bitcoin uses blockchain to maintain a public ledger of all transactions without needing a central bank.

---

## Key Takeaways

- Blockchain is a distributed ledger.
- It removes the need for central authorities.
- Data is secured using cryptography.
- Once recorded, data is very difficult to change.
